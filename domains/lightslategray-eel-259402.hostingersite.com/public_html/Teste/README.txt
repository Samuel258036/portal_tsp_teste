TSP ADVOGADOS - AREA DO CLIENTE PHP (DEMO)

Objetivo:
Versao PHP simples para testar diretamente na hospedagem Hostinger, sem Node.js.

COMO PUBLICAR:
1. Abra o Gerenciador de Arquivos do site temporario.
2. Entre na pasta public_html.
3. Remova apenas os arquivos de teste desse site temporario (nao mexa no tsp.adv.br).
4. Envie o ZIP tsp-area-cliente-php.zip para public_html.
5. Extraia o ZIP.
6. IMPORTANTE: os arquivos index.php, inicio.php etc. precisam ficar diretamente dentro de public_html.
   Se a extracao criar uma pasta tsp-area-cliente-php, mova o conteudo dela para public_html.
7. Abra o dominio temporario no navegador.
