Como instalar:

2. Envie o ZIP para /public_html/v4/
3. Extraia DIRETAMENTE em /public_html/v4/
4. Marque sobrescrever arquivos existentes.
5. Confirme que database.php continua no diretório.
6. Faça login usando o Admin real criado no banco.
7. Admin > Clientes: cadastre clientes.
8. Admin > Usuários e acessos: crie os acessos dos quatro perfis.
